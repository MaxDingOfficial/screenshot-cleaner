# 截屏清理 · Screenshot Cleaner

一个原生 macOS 小工具，按时间筛选截屏，预览后将选中的图片移至废纸篓或彻底删除。

由 **MaxDingOfficial** 发起并维护，使用 OpenAI Codex 辅助开发。

## 功能

- 默认扫描桌面，也可以选择其他文件夹。
- 按天、月、年筛选超过指定时间的截屏。
- 可选扫描普通子文件夹，跳过隐藏文件、符号链接、应用程序包和照片图库。
- 预览文件清单、日期及大小，逐张勾选或取消。
- 支持原生废纸篓与直接删除；直接删除要求输入确认文字。
- 处理前重新核对文件身份、内容、截屏标记和日期；有变化的文件跳过。
- 保存最近 100 次清理记录，全程在本机处理图片。

## 运行

最低系统版本：macOS 13。构建产物包含 Apple 芯片及 Intel 两种架构。

当前版本已在 Apple 芯片 Mac 上启动并验证。Intel 版本完成编译，尚未在 Intel 机器上运行测试。

在 [Releases](https://github.com/MaxDingOfficial/screenshot-cleaner/releases) 下载应用压缩包，解压后打开。

双击构建得到的 `截屏清理.app`，或者拖入“应用程序”文件夹。第一次访问受保护文件夹时，按 macOS 提示授予相应访问权限。

此版本使用本地临时签名，尚未通过 Apple 公证，分发后可能出现系统打开提示。

## 从源码构建

需要 macOS 和 Apple Command Line Tools，无需第三方依赖。

```sh
zsh build.sh
```

产物位于 `build/截屏清理.app`。也可以向构建脚本传入输出目录：

```sh
zsh build.sh /绝对路径/输出目录
```

## 验证

```sh
zsh test.sh
```

现有 22 项检查覆盖日历月份、闰年、截止时间、英文 AM/PM、截屏识别、子文件夹、同名文件、移至废纸篓、直接删除及预览后的文件变化。测试只生成和处理自己的临时图片。

界面已检查文件夹选择、逐张勾选、子文件夹预览和直接删除确认。确认界面测试取消了最终删除操作。

## 日期与识别规则

“超过 2 个月”按日历月份计算，不固定换算成 60 天。恰好等于截止时间的文件保留。

系统截屏文件名中的时间优先；已改名且仍保留 macOS 截屏标记的图片采用文件创建日期。日期依据可在清单的日期提示中查看。

缺少截屏标记、名称也不符合系统截屏格式的图片不会自动纳入清理。直接删除是文件系统删除，不是对存储介质做安全擦除。

## 隐私与记录

没有网络请求，不上传图片，不定时自动删除。

历史记录只保存操作时间、方式、文件路径和结果，不保存图片内容，位于：

```text
~/Library/Application Support/ScreenshotCleaner/history.json
```
